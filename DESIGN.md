# SHODHA AI design system
The workspace uses a dark instrument panel with a prominent entry to investigation and a quieter case ledger. Its abstract aperture is brand artwork. Only the separately labeled report charts represent measurements.

| Token | Value | Use |
| --- | --- | --- |
| Field | #0b1018 | Page |
| Panel | #101824 | Case surfaces |
| Rule | #283647 | Boundaries |
| Ink | #edf4fc | Primary text |
| Secondary | #a7b6c8 | Descriptions |
| Cyan | #66d9ed | Focus and signal |
| Blue | #2362cc | Primary action |
| Green, coral, amber | #79dfbd, #ff9c99, #f1cb85 | Real, AI-generated, inconclusive |

Use locally served Manrope for navigation and prose, tabular monospace for identifiers and measurements. Keep case and frame records on ruled rows. Use persistent text labels alongside outcome color. Preserve keyboard focus, reduced motion, mobile reflow and readable error recovery.
